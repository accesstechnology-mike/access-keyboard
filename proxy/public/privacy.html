access: keyboard is an assistive iPad keyboard.

Full Access is requested so Beth mode can be shared with the keyboard extension, and so Fix can call the correction proxy. Keystrokes stay on the device. Tapping Fix sends the current field’s text to that proxy and does not store it there.

The Release proxy is https://access-keyboard.vercel.app/api/fix. It forwards that field to OpenAI with store disabled. Ordinary keystrokes are not sent. Password fields are skipped.

Beth mode and learned predictions stay in the app group on the iPad.
