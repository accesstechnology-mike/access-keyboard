access: keyboard privacy

access: keyboard is an assistive keyboard for iPhone and iPad.

Typing stays on your device. The keyboard does not send keystrokes anywhere. It remains usable with Full Access turned off and with no network connection.

The keyboard can learn which words you type next, so the suggestion bar can offer them later. That learning is done on the device by PredictionMemory and stored in the shared App Group (group.6M3Z27M69P.app.access.keyboard) when Full Access is on. It is not sent off the device. Without Full Access, the system keyboard still types and can still learn inside the keyboard, but it does not open that shared App Group, so those words stay in the keyboard and are not shared with the access: keyboard app.

Fix is optional. Nothing is sent unless you tap Fix. When this build asks for consent, the text is sent only after you tap Allow. You can turn that permission off in the access: keyboard app’s Settings, and the next Fix will ask again. Tapping Fix sends only the current text field to the correction proxy at https://access-keyboard.vercel.app/api/fix. That proxy forwards the field to OpenAI with store disabled and does not keep the text. Ordinary keystrokes are not included. Password fields are skipped. If Full Access is off, or the device has no network, Fix does not send anything.

Full Access is requested so colour and layout settings, and the on-device learned predictions, can be shared with the keyboard extension, and so Fix can reach that proxy.
